## 기획 확인 필요
- Z3: 머리를 밟고 턱으로 뛸 때 여유가 0.07m뿐이다(최고 13.27, 턱 13.2). 받침대를 올리면 2단 박스에서 받침대까지가 1.6m가 되어 못 오른다. 턱을 낮추는 쪽을 권한다.
- Z3: 전용 박스(빨강·파랑)가 없어도 1단 + 2단 박스로 계단이 완성된다. "특수 박스 필수"가 아니다.
- Z1: 배치 1만 개 중 41%는 자기 색만 따라가면 막다른 길이 나온다(빨강 22.6%, 파랑 22.3%). 뒤로 돌아가면 되므로 막히지는 않지만, 서로 말로 알려 주는 것이 필수다. 줄마다 안전 칸 1개(50.1%) / 2개(49.9%).
- Z2: 상대가 일찍 밟으면 내 발판이 즉시 사라져 Z2 전체가 처음으로 돌아간다. 수평 발판 가운데에서는 여유 시간을 줘도 대기석에 닿지 않는다. "내가 내릴 때까지 내 발판 유지" 같은 규칙이 효과적이다.
- Z3 출구(임시): 다리 끝에서 걸어 나가면 바로 매달린다. 7m 아래에 임시 발판이 있다.
