# 치트키 목록 (개발·테스트용)

최종 갱신: 2026-10-28

- 모든 치트키는 **에디터 / Development Build에서만** 동작한다. 정식 빌드에는 들어가지 않는다.
- 새 키를 쓰기 전에 `계약명세.md` §7.1 표에 먼저 등록한다 (키 겹침 방지).

---

## 1. 이동

| 키 | 기능 | 비고 |
| --- | --- | --- |
| **F5** | 마지막 체크포인트에서 다시 시작 | 체크포인트를 안 밟았으면 시작 위치로. 오프라인·온라인 모두 |
| **F6** | 다음 체크포인트로 이동 | 마지막 다음은 처음으로 돌아감. 죽어 있는 동안은 안 됨 |
| **`** (숫자 1 왼쪽) | 명령 입력창 열기 | 아래 명령 참고. Enter 실행, Esc 닫기 |

### ` 명령창 명령

| 명령 | 기능 |
| --- | --- |
| `move hammer` | 공용 해머(`Hammer_Common`) 근처로 이동 |
| `move hammerb` | 파랑 전용 해머(`Hammer_Blue_OnlyB`) 근처로 이동 |
| `move z1` ~ `move z5` | 구간 Z1~Z5 근처로 이동 |
| `move <이름>` | 이름 일부만 맞아도 그 오브젝트 근처로 이동 |
| `list` | 이동 가능한 대상 목록을 콘솔에 출력 |

- 대상에서 3m 떨어진 땅에 내려주고, 대상을 바라보게 한다.
- `NetBootstrap`이 있는 씬에서만 쓸 수 있다. 내 캐릭터만 옮긴다.
