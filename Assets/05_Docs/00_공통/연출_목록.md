# 연출 목록

최종 갱신: 2026-11-18

오브젝트·기능 구현 뒤 필요한 연출(애니메이션·이펙트·카메라·피드백)을 적는다.
연출 제작은 `개발_클라이언트_연출_Dotween_Feel 세션`에 요청한다. 연출은 각 PC에서 따로 재생한다 (동기화된 상태 변화에 맞춰 각자 켠다).

| 대상 | 연출 (한 줄) | 언제 켜지나 | 도구 | 상태 |
|---|---|---|---|---|
| 플레이어 사망 (추락) | 추락 지점(KillZone)에 닿은 플레이어가 가루가 되어 흩어지고, n초 뒤 리스폰 지점에서 다시 나타남 | 사망 순간 (`PlayerEvent.Died`, 상대 PC는 원격 이벤트로 같이 받음) → 부활 (`PlayerEvent.Respawned`) | Feel (+ 파티클) | 구현함 (PlayerDeathFx) |
| 플레이어 엎드리기 | 엎드리기·엎드려 기기·일어나기 애니메이션 | Animator Bool `Prone` | 애니메이션 (아트팀장 세션) | 요청함 |
