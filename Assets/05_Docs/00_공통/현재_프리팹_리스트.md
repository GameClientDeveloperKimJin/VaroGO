## 먼저 알아둘 것: 누구에게 보이나


| 색       | 플레이어 A (빨강 담당) | 플레이어 B (파랑 담당) |
| ------- | -------------- | -------------- |
| 회색 (공용) | 보임             | 보임             |
| 빨강      | 보임             | **안 보임**       |
| 파랑      | **안 보임**       | 보임             |


- 안 보여도 **밟을 수 있고 부딪힌다.** 보이는 사람이 말로 알려줘야 지나갈 수 있다. 이게 이 게임의 핵심 재미다.

연결 방법: 문(또는 시간제한 발판)의 **State Object** 칸에 스위치 오브젝트를 끌어다 놓는다. (예전 이름 State Source. 기존 연결은 그대로 동작한다)

**자주 쓰는 설정**


| 하고 싶은 것                     | 설정                                     |
| --------------------------- | -------------------------------------- |
| 스위치를 일정 시간 뒤 자동으로 꺼지게       | 스위치의 Auto Off Seconds에 초 입력 (0 = 안 꺼짐) |
| 밟고 있는 동안만 켜지게 (버티기)         | 발판 스위치의 Off When Left 체크               |
| 스위치를 켜면 문이 **닫히게** (장난 스위치) | 문의 Invert 체크                           |
| 문이 열리는 방향, 속도               | 문의 Open Offset, Move Time              |
| 처음부터 켜진 스위치                 | 스위치의 Start On 체크                       |


**퍼즐 리셋 (죽어도 퍼즐은 그대로)**

- 죽으면 부활만 한다. 스위치·문은 **그대로** 남는다.
- 퍼즐이 꼬였을 때 **퍼즐 리셋 버튼**에서 E키 → 같은 구역 번호의 스위치가 모두 처음 상태(Start On)로 돌아간다. 문도 따라서 닫힘/열림.
- 설정: 한 퍼즐에 속한 스위치들의 **Zone** 칸에 같은 번호(예: 1)를 넣고, 리셋 버튼의 **Zone**에도 같은 번호를 넣는다. Zone 0은 기본값이라, 리셋을 쓸 퍼즐은 1부터 번호를 주는 걸 추천.
- 리셋 버튼 설정: Zone(되돌릴 구역 번호), Cooldown(다시 누를 수 있을 때까지 초, 기본 1).
- 장애물(움직이는 발판·망치 등)은 시간에 맞춰 움직여서 리셋 대상이 아니다.
- 온라인: 서버 쪽 리셋 기능이 붙어야 동작한다 (그 전엔 눌러도 삑 소리만 남).

**역할 교차 퍼즐 만들기** (A가 B의 문을 열고, B가 A의 문을 연다)

1. A 전용 세트를 씬에 놓고 우클릭 → Prefab → Unpack.
2. 문만 B가 가는 길로 옮긴다. 연결은 그대로 유지된다.
3. 반대쪽은 B 전용 세트로 똑같이 한다.

## 4. 진행 (체크포인트 · 낙사 · 골)


| 이름    | 경로                                                          | 설명                      |
| ----- | ----------------------------------------------------------- | ----------------------- |
| 체크포인트 | `Assets/02_Prefabs/Client/Level/Progress/Checkpoint.prefab` | **두 사람 모두** 밟으면 저장. 죽은 사람만 여기서 다시 시작 (파트너는 그대로). 접속이 끊겼다 다시 들어오면 저장된 체크포인트에서 이어서 시작 |
| 낙사 구역 | `Assets/02_Prefabs/Client/Level/Progress/KillZone.prefab`   | 닿으면 죽고 저장된 체크포인트로 돌아감. 화면에 원인 메시지가 뜬다: 파트너에게 밀린 뒤 3초 안이면 "○○에게 밀려 떨어짐", 아니면 "혼자 떨어짐"   |
| 골     | `Assets/02_Prefabs/Client/Level/Progress/Goal.prefab`       | **두 사람 모두** 들어오면 CLEAR  |


- 체크포인트는 Order 값을 코스 순서대로 0, 1, 2… 로 **늘려가며** 준다. 구간마다 1개, 휴식 공간에 둔다.
  - 발판 색: **회색** 아무도 안 밟음 · **노랑** 한 명만 밟음 · **초록** 둘 다 밟아 저장됨.
  - 두 사람이 모두 지나가는 자리에 둔다 (역할별로 길이 갈리는 곳에 두면 저장이 안 된다).
  - Inspector: `Order` 코스 순서 · `Spawn Point` 다시 시작할 위치·방향(비우면 발판 위치) · `Idle/Half/Active Color` 상태별 색.
  - 혼자 테스트(오프라인)는 한 명만 밟아도 저장된다. 씬의 `OfflineBootstrap`에서 `Checkpoint Require Both`를 켜면 F1·F2로 역할을 바꿔 두 번 밟아야 저장(온라인 규칙 확인용).
- 낙사 구역은 떨어지는 경로 아래에 넓게 깐다. 길이 위아래로 겹치는 곳(아래층 길이 있는 곳)은 아래층 길을 덮지 않게 **코스 바깥쪽**에 둔다.
- 골은 코스 맨 끝에 1개.
  - CLEAR 뒤 **바로** 다음 씬으로 넘기려면 골에 `StageExit` 컴포넌트를 붙인다: `Goal State Object` = 골 자신, `Next Scene Path` = 다음 씬 경로(Build Settings에 있어야 함), `Delay` = CLEAR 뒤 넘어가기까지(초, 기본 4). 온라인은 방장이 바꾸고 둘 다 같이 넘어간다.
  - 스테이지 1처럼 CLEAR 뒤 **비행 보너스**를 거쳐 넘어가는 곳은 `StageExit`를 붙이지 않는다 (비행 세트가 착륙 뒤 넘긴다, §6).

## 5. 상호작용 · 기믹 (1스테이지)

> **2인 온라인용**: 밀기 돌·바위·통나무, 돌멩이, 숨겨진 발판, 도토리 도둑 다람쥐는 이름 끝에 `_Net`이 붙은 버전을 쓴다. 두 사람 화면에서 위치·상태가 같이 맞춰진다. 혼자 테스트에서도 그대로 동작한다.
> 점프 버섯·수액·나뭇가지는 `_Net` 버전이 없다 (각자 화면에서 판정해도 결과가 같다).

**조작 (플레이어)**

| 하고 싶은 것 | 방법 |
| --- | --- |
| 물건 밀기 | 물건 쪽으로 **그냥 걸어 들어가기** (키 없음). 다른 방향으로 걸으면 멈춤. 큰 바위는 둘이 같은 방향으로 같이 걸어야 움직인다 |
| 파트너 밀기 | 파트너 앞에서 **F** (점프 버섯·수액 쪽으로 밀어 보낼 수 있다). F는 이제 파트너 밀기에만 쓴다 |
| 절벽 붙잡기 | 떨어지다 모서리를 지나면 **자동으로** 매달린다. 앞(벽 쪽) 또는 점프 = 올라가기, 뒤 = 놓기 |
| 돌멩이 줍기·던지기 | 돌 근처에서 **E** = 줍기, 다시 **E** = 카메라가 보는 쪽으로 던지기 |
| 묶인 파트너 구하기 | 파트너 옆에서 **A/D를 번갈아** 누르기 |

## 6. 공중 비행 보너스 (스테이지 1 → 스테이지 2 사이)

> 스테이지 1 씬 안에서 이어진다 (씬 안 바뀜). 골 뒤에 하늘 갑판이 있다.
> 흐름: 스테이지 1 골 CLEAR → 갑판에 수정구슬이 나타남 → 만지기(E) → 도우미가 뗏목 소환 → 둘 다 탑승 → 3·2·1 → 자동 전진 비행 → 착륙 → 몇 초 뒤 **스테이지 2 씬**(`Assets/01_Scenes/PlayScene_Stage2.unity`)으로 넘어감.
> CLEAR 전에는 수정구슬이 보이지 않는다.
> 조작: **빨강(A) = A키로 왼쪽**, **파랑(B) = D키로 오른쪽**. 둘 다 누르거나 둘 다 안 누르면 직진. 혼자 테스트에선 한 사람이 A·D 둘 다 쓴다.
> 뗏목 내구도 4. 장애물에 맞으면 1 깎이고 1.5초 동안 무적. 0이 되면 **처음(출발 전)부터 다시**.
