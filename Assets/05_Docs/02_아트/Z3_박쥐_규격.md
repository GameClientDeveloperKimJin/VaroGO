# Z3 동굴 박쥐 규격 (아트 → 맵 디자인 · 개발)

> 2026-11-22 · 메시 `Assets/04_Resources/KIMJIN_ArtWork/Model/Z3_Bat/` · 재질 `Assets/04_Resources/KIMJIN_ArtWork/Material/Z3_Bat/`

미터 단위, 스케일 1로 구워 두었다. 날개폭(끝에서 끝) 약 0.88m.

| 파일 | 내용 | 삼각형 |
|---|---|---|
| `Bat_Body.obj` | 몸통(머리·귀·발 포함). 몸통 중심이 원점, 정면 +Z, 위 +Y. 크기 폭 0.30 × 높이 0.40 × 깊이 0.40. 임포트에서 Mesh LOD 자동 생성을 켬 | 2,258 |
| `Bat_Wing_L.obj` | 왼쪽 날개. **원점 = 어깨**, 날개가 -X로 펼쳐짐(-0.31), 앞뒤(Z) -0.16~+0.14, 평평한 막 | 128 |
| `Bat_Wing_R.obj` | 오른쪽 날개. 원점 = 어깨, +X로 펼쳐짐 | 128 |

| 재질 | 용도 |
|---|---|
| `M_CaveBat_Body` | 몸통 (URP Lit, 1024 텍스처, 반들거림 낮음) |
| `M_CaveBat_Wing` | 날개 (Alpha Clipping 0.5, 양면, 날개 모양 알파) |

## 프리팹 구성 (맵 디자인 세션 규칙)
```
CaveBat (루트 = 몸통 중심, 콜라이더 없음)
 ├ Body      MeshFilter Bat_Body.obj + MeshRenderer M_CaveBat_Body   위치 (0,0,0)
 ├ Wing_L    MeshFilter Bat_Wing_L.obj + MeshRenderer M_CaveBat_Wing 위치 (-0.13, -0.02, 0)
 └ Wing_R    MeshFilter Bat_Wing_R.obj + MeshRenderer M_CaveBat_Wing 위치 ( 0.13, -0.02, 0)
```
- 자식 이름은 `Wing_L`, `Wing_R`. 날개 오브젝트 자체가 메시를 가지고, 피벗 = 어깨다.
- 그림자: 날개는 Cast Shadows Off 권장(알파 클립 그림자가 부담).

## 날개 퍼덕임 (Z축 회전, localEulerAngles.z)
- 평소 자세(z = 0): 날개가 몸통 양옆으로 수평으로 펴짐.
- **Wing_L**: 위로 -35°, 아래로 +25° 사이를 왕복
- **Wing_R**: 부호 반대. 위로 +35°, 아래로 -25° 사이를 왕복
- 두 날개는 같은 박자로 움직이면 된다(대칭).
- 박자는 초당 3~5번(느린 박쥐 1.5~2.5Hz도 자연스러움). 박쥐마다 시작 위상을 무작위로 주면 한꺼번에 움직이지 않는다.

## 매달린 포즈 (선택)
- 루트를 X축으로 180° 뒤집어 거꾸로 매단다.
- 날개 접기: Wing_L z = +85°, Wing_R z = -85° (몸통 옆으로 모음). 필요하면 날개 스케일을 (1, 1, 0.7)로 줄여 몸통에 붙인다.
- 같은 부품을 쓰므로 모델은 더 필요 없다.
