# 2주차 작업지시서 — 01. 클라이언트

**담당:** 클라이언트 개발자  
**네임스페이스:** `VaroGO.Client`, `VaroGO.Shared`  
**선행 문서:** `계약명세.md`, `전달_서버_to_클라.md`, `2주차_02_서버.md` §2

> **2주차 목표: 시스템 뼈대 (MVP)**
> 온라인 세션 UI, 공유 체크포인트·부활, 플레이어 밀기 — 세 시스템의 **화면·판정·연출** 을 만든다. 클라는 Shared 인터페이스만 보고, 동기화는 서버가 구현한다. 오프라인(`OfflineServices`)에서도 전부 돌아가야 한다.

### 2.3 체크포인트·부활

| ID | 작업 | 내용 | 완료 기준 |
| --- | --- | --- | --- |
| **C2-05** | 체크포인트 = 도착 보고만 | `Checkpoint` 트리거 → 로컬 플레이어면 `ICheckpointState.ReportReached(Order, 내 역할)`. `PlayerRespawn` 은 개인 체크포인트 대신 `ActiveOrder` 지점에서 부활. 표시: 한 명 도착 = 반쯤 켜짐, 둘 다 = 활성 | 죽은 사람만 공유 체크포인트에서 부활, 다른 사람은 그대로 |
| **C2-06** | 사망 ≠ 퍼즐 리셋 | 죽음은 부활만. 퍼즐 리셋은 별도 요청(키/버튼) → `IZoneReset.RequestReset`. `LocalSwitchState` 에 `Zone` 값 추가(서버가 읽음). `ZoneReset` 받으면 로컬 장애물 상태 초기화 | 죽어도 스위치 그대로, 리셋 요청 시만 초기화 |
| **C2-07** | 사망 원인 판정·메시지 | 밀린 PC가 "마지막으로 민 사람·시각" 기록. 밀린 뒤 N초(예: 3초) 안에 죽으면 "○○에게 밀려 떨어짐", 아니면 "혼자 떨어짐" 메시지 | 두 경우 메시지 구분됨 (오프라인 포함) |
| **C2-08** | (임시 채택) 빠른 이동 | 활성 체크포인트 목록 UI → 선택 → `CanFastTravel` OK면 `Teleport` 즉시 이동 | 낮은 우선순위. 시간 남을 때 |

## 5. 2주차 완료 시나리오 (두 PC로 확인)

1. 방 만들기 → 코드 참가 → 게스트 Ready → 호스트 Start → 코스 진입
2. 게스트 창 종료 → 호스트 대기 화면 + 장애물 정지 → 재참가 → 이어서 진행
3. 체크포인트: 한 명만 = 반쯤, 둘 다 = 활성
4. 한 명 낙사 → 그 사람만 활성 체크포인트에서 부활 / 리셋 요청 시 두 PC 초기화
5. 밀기 → 상대 넉백 → 떨어지면 "밀려 떨어짐", 혼자면 "혼자 떨어짐"
6. 파트너 화면 밖 → 가장자리 화살표
7. 레벨 오브젝트 바뀐 것 프리팹·`현재_프리팹_리스트.md` 반영
