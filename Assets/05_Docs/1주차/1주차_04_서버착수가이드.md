- Set_* 는 중첩 프리팹. Variant에서 중첩 인스턴스 컴포넌트 제거가 되는지 **확인 필요**. 안 되면 Set 안의 레버/발판을 `_Net` 버전으로 바꿔 끼우는 방식 검토.
- 교체할 때 직렬화 필드 값(allowedRole, autoOffSeconds, startOn)이 그대로 넘어가는지 확인.

## 6. 오프라인 테스트 방법

씬: `Assets/01_Scenes/11_SpiralCourse.unity` (코스). `10_DemoRoom.unity`는 오브젝트 샘플 — **저장 금지**.

| 키 | 동작 | 조건 |
| --- | --- | --- |
| F1 / F2 | 역할 A_Red / B_Blue 로 보기 | 오프라인 등록일 때만 |
| F3 | 전부 보기 (디버그) | 〃 |
| F5 | 마지막 체크포인트에서 다시 시작 | 로컬 플레이어 |
| F6 | 다음 체크포인트로 이동 | 로컬 플레이어 |
| F7 / F8 | 원격 플레이어 이벤트 연출 테스트 | 오프라인 + 원격 플레이어 있을 때 (클라 전용) |
| F9 / F10 | 서버 전용 예약 | — |

모든 디버그 키는 `UNITY_EDITOR || DEVELOPMENT_BUILD`에서만.

확인 순서:
1. 플레이 → 좌상단 ROLE 표시 확인.
2. F1 ↔ F2: 빨강/파랑 발판이 번갈아 보이는지 (안 보여도 밟힘).
3. 해머가 움직이는지 (시계 동작 확인).
4. 스위치 밟기 → 문 열림, 역할 다르면 안 열림.
5. KillZone 낙하 → 체크포인트 부활, F5/F6.
6. 골 진입 → CLEAR, R 재시작.

온라인 붙인 뒤 같은 순서를 PC 2대에서 반복: 2번은 PC마다 다르게 보여야 하고, 3번은 두 화면 타이밍이 같아야 한다.

서버 MD·계약 문서는 수정하지 않음. 계약 수준 항목(★)은 팀장 세션에 제안으로 전달.

| --- | --- | --- | --- | --- |
| 1 | 씬 이름 | `00_Boot`(0), `10_DemoRoom`(1) 빌드 등록, 데모룸 로드 | `00_Boot` 없음. 빌드 세팅엔 `PlayScene_Merge`만. 코스는 `11_SpiralCourse`. `10_DemoRoom`은 저장 금지 샘플. 공통 §4.2의 `11_DemoRoom_Offline`도 실제와 다름 | 온라인 대상 씬 = `11_SpiralCourse`로 합의 ★ |
