# 1주차 작업지시서 — 01. 클라이언트

**담당:** 클라이언트 개발자  
**브랜치:** `Client---System_Content`  
**네임스페이스:** `VaroGO.Client`  
**선행 문서:** `1주차_00_공통.md` (공통 계약, 브랜치·소유권 규칙)

> **한 줄 요약:** 네트워크 없이 혼자서 플레이할 수 있는 "재미의 본체"를 만든다. 코드는 Fusion을 참조하지 않고, 공통 계약(`VaroGO.Shared`)만 사용한다.

---

## 0. 원칙

1. **Fusion 의존성 0.** `VaroGO.Client` 코드에서는 `using Fusion;`을 쓰지 않는다. 네트워크는 서버 담당이 인터페이스로 연결한다.
2. **시간은 `GameServices.Clock.Now`만 사용한다.** 이동 장애물에서 `Time.time`을 직접 쓰면 온라인에서 두 화면의 위치가 어긋난다.
3. **역할은 `GameServices.Role.LocalRole`만 사용한다.** 역할 값을 따로 캐싱하지 말고, `LocalRoleChanged`를 구독한다.
4. **수치는 ScriptableObject로 뺀다.** 기획자가 코드 수정 없이 튜닝할 수 있게 한다.
5. **그레이박스로 충분하다.** 큐브와 캡슐로 재미부터 확인한다.

### C-03. 플레이어 이동 — `PlayerController : MonoBehaviour, IPlayerSimulation`

- Unity `CharacterController`를 기반으로 한다.
- 수치는 `PlayerTuning` ScriptableObject로 뺀다.

```csharp
[CreateAssetMenu(menuName = "VaroGO/PlayerTuning")]
public class PlayerTuning : ScriptableObject
{
    public float moveSpeed = 6f;
    public float acceleration = 40f;
    public float jumpHeight = 1.6f;
    public float gravity = -25f;
    public float coyoteTime = 0.1f;      // 발판에서 떨어진 직후에도 점프 허용
    public float jumpBuffer = 0.1f;      // 착지 직전 점프 입력 허용
    // 넉백 (C-09)
    public float lightPushSpeed = 3f;
    public float heavyKnockbackSpeed = 14f;
    public float heavyKnockbackUp = 6f;
    public float airControlDuringKnockback = 0.08f; // 0~1, 매우 작게
    public float heavySpeedThreshold = 5f;          // 장애물 속도가 이 값을 넘으면 강한 넉백
}
```

- `IPlayerSimulation` 구현
  - `SetLocal(false)`: 입력, 카메라, `CharacterController` 이동을 끈다. Transform은 네트워크가 움직인다.
  - `Simulate(dt)`: 이동, 점프, 중력, 넉백 상태를 처리한다. **물리 이동은 여기서만 한다.**
  - `Teleported`: 부활할 때 발생시킨다.
  - `EventRaised`: `Died`, `Respawned`, `KnockbackLight`, `KnockbackHeavy`, `Landed`, `HitInvisible`
- 이동 방향은 카메라 기준이며, 캐릭터는 이동 방향을 바라본다.
- Animator 파라미터: `Speed`(float), `Grounded`(bool), `Jump`(trigger), `Knockback`(trigger), `Airborne`(bool). 서버가 `NetworkMecanimAnimator`로 동기화하므로 **파라미터 이름을 바꾸면 서버에 알린다.**
- 움직이는 발판 위에 서 있을 때 발판을 따라 움직이게 한다(P1. 발판의 프레임 이동량을 더한다).

**완료 조건**

- [x] 이동, 점프, 코요테 타임, 점프 버퍼가 동작한다.
- [x] `PlayerTuning` 값을 플레이 중에 바꾸면 바로 반영된다.

### C-08. 이동 장애물 (시계 기반)

- **모든 위치·회전은 `GameServices.Clock.Now`의 함수로 계산한다.** 상태를 누적하지 않는다.
  ```csharp
  double t = GameServices.Clock.Now + phaseOffset;
  float s = Mathf.Sin((float)(t * speed));
  rb.MovePosition(origin + axis * (s * amplitude));
  ```
- Kinematic `Rigidbody`를 쓰고 `MovePosition` / `MoveRotation`으로 움직인다.
- 현재 속도도 해석적으로 계산해서 넉백에 넘긴다: `Vector3 GetVelocityAt(Vector3 worldPoint)`
- 종류 (공통 베이스 `ClockDrivenObstacle`)
  - `SlidingObstacle`: 왕복 이동 (느림 → 밀림)
  - `RotatingHammer`: 축 회전 또는 진자 (빠름 → 날아감)
  - `Pusher`: 일정 주기로 튀어나오는 벽 (빠름 → 날아감)
  - `MovingPlatform`: 사람이 타는 발판
- 마법 장애물은 `MagicVisibility`와 함께 쓸 수 있어야 한다(보이지 않는 해머).

**완료 조건**

- [ ] `OfflineGameClock`에 임의의 오프셋을 줘도 장애물이 그 시간에 맞는 위치로 즉시 이동한다(상태 누적이 없다는 증거).
- [ ] 장애물마다 `phaseOffset`으로 타이밍을 어긋나게 할 수 있다.

### C-09. 넉백과 공중 보정 (GDD 7.3, 7.4)

- 피격 판정은 **로컬 플레이어 기준**으로 한다(`OnControllerColliderHit` 또는 장애물 쪽 트리거).
- 장애물 속도 `v = obstacle.GetVelocityAt(hitPoint)`
  - `|v| < heavySpeedThreshold`: **가볍게 밀림** — 진행 방향으로 `lightPushSpeed`만큼 밀어내고 조작은 유지된다. `KnockbackLight`
  - `|v| ≥ heavySpeedThreshold`: **강한 넉백** — `v` 방향 수평 성분 × `heavyKnockbackSpeed` + 위쪽 `heavyKnockbackUp`. 전용 공중 상태로 들어간다. `KnockbackHeavy`
- 강한 넉백 공중 상태
  - 이동 입력은 `airControlDuringKnockback` 비율로만 반영한다(**방향을 뒤집을 수 없다**).
  - 점프 입력은 무시한다.
  - 착지하면 일반 상태로 돌아가고 `Landed`를 발생시킨다.
- 정지 장애물은 이동만 막고 넉백은 없다.
- 넉백 연출: 캐릭터가 빙글빙글 도는 임시 모션(Transform 회전으로 대체해도 된다). **웃겨야 한다.**

**완료 조건**

- [ ] 느린 장애물은 밀어내고, 빠른 해머는 날려 보낸다.
- [ ] 날아가는 동안 방향을 아주 조금만 바꿀 수 있다.
- [ ] 안전한 지형에 떨어지면 살고, 낭떠러지로 떨어지면 C-10의 사망으로 이어진다.

### C-10. 사망·개인 부활·체크포인트 (GDD 7.5)

### C-11. 스위치·문·시간제한 발판

- **상태(`ISwitchState`)와 연출을 분리한다.** 연출 컴포넌트는 `ISwitchState.Changed`만 구독한다. 그래야 서버가 상태 구현체만 `NetSwitchState`로 바꿀 수 있다.
- `LocalSwitchState : MonoBehaviour, ISwitchState`
  - 필드: `PlayerRole allowedRole`, `float autoOffSeconds`, `bool startOn`
  - `RequestSet`: `allowedRole`이 None이 아니고 요청자와 다르면 무시한다.
  - `autoOffSeconds > 0`이면 켜진 뒤 그 시간이 지나면 자동으로 꺼진다(시간제한 발판).
- 입력 측 (요청을 보내는 쪽)
  - `PressurePlate`: 로컬 플레이어가 올라가면 `RequestSet(true, GameServices.Role.LocalRole)`. 내려왔을 때 꺼질지는 옵션
  - `Lever`: 범위 안에서 `Interact`를 누르면 토글
  - **원격 플레이어는 요청을 보내지 않는다.** (온라인에서 중복 요청 방지. 로컬 플레이어 여부는 `PlayerController`의 `IsLocal`로 판정)
  - 권한이 없는 역할이 누르면 "삑" 효과음만 낸다.
- 출력 측 (상태를 표현하는 쪽)
  - `Door`: on이면 열린다(위치 Lerp). Collider도 함께 움직인다.
  - `TimedPlatform`: on인 동안만 Collider와 Renderer가 켜진다. 꺼지기 1초 전에 깜빡인다.
  - 모두 `ISwitchState` 참조를 Inspector에서 연결한다(`[SerializeField] MonoBehaviour stateSource` → `ISwitchState`로 캐스팅).
- 전용 스위치는 색과 문양으로 누가 누를 수 있는지 표시한다.

**완료 조건**

- [ ] A 전용 스위치는 F1 상태에서만 동작한다.
- [ ] 시간제한 발판이 설정한 시간 뒤에 꺼지고, 꺼지기 전에 깜빡인다.
- [ ] 연출 컴포넌트가 `LocalSwitchState`를 직접 참조하지 않는다(인터페이스만 사용).

- `ChapterCleared` → 화면 중앙에 "CLEAR!" + 효과음 + 3초 뒤 "R: 다시 하기" 안내
- 클리어 UI는 `IGoalState`만 구독한다.
