## 먼저 알아둘 것: 누구에게 보이나


| 색       | 플레이어 A (빨강 담당) | 플레이어 B (파랑 담당) |
| ------- | -------------- | -------------- |
| 회색 (공용) | 보임             | 보임             |
| 빨강      | 보임             | **안 보임**       |
| 파랑      | **안 보임**       | 보임             |


- 안 보여도 **밟을 수 있고 부딪힌다.** 보이는 사람이 말로 알려줘야 지나갈 수 있다. 이게 이 게임의 핵심 재미다.
- 테스트 키 (플레이 중): **F1** A로 보기 · **F2** B로 보기 · **F3** 전부 보기 · **F5** 마지막 체크포인트에서 다시 시작 · **F6** 다음 체크포인트로 이동

| 푸셔      | `Assets/02_Prefabs/Client/Level/Obstacles/Pusher.prefab`         | 갑자기 튀어나와 밀고 천천히 들어간다              |
| 움직이는 발판 | `Assets/02_Prefabs/Client/Level/Obstacles/MovingPlatform.prefab` | 두 지점 사이를 오가는 발판. 올라타면 같이 이동       |


조절할 수 있는 값 (Inspector):


| 값                               | 의미                                | 쓰는 곳         |
| ------------------------------- | --------------------------------- | ------------ |
| Axis                            | 움직이는 방향                           | 슬라이더, 망치, 푸셔 |
| Amplitude / Distance            | 움직이는 거리                           | 슬라이더 / 푸셔    |
| Period                          | 한 번 왕복하는 데 걸리는 시간(초). **작을수록 빠름** | 슬라이더, 망치, 푸셔 |
| Mode                            | Pendulum = 흔들림, Spin = 회전         | 망치           |
| Max Angle                       | 흔들리는 각도                           | 망치           |
| Phase Offset                    | 시작 타이밍 어긋나게 하기                    | 여러 개 나란히 둘 때 |
| Travel / Move Time / Pause Time | 이동 거리 / 이동 시간 / 끝에서 멈추는 시간        | 움직이는 발판      |


- 장애물은 두 플레이어 화면에서 **똑같은 타이밍**으로 움직인다.
- 같은 장애물을 여러 개 나란히 놓으면 동시에 움직이니, Phase Offset을 다르게 줘서 엇갈리게 한다.

| 이름                      | 경로                                                                                                                               |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------- |

| 문                       | `Assets/02_Prefabs/Client/Level/Switches/Door.prefab`                                                                            |
| 시간제한 발판                 | `Assets/02_Prefabs/Client/Level/Switches/TimedPlatform.prefab`                                                                   |


연결 방법: 문(또는 시간제한 발판)의 **State Object** 칸에 스위치 오브젝트를 끌어다 놓는다. (예전 이름 State Source. 기존 연결은 그대로 동작한다)

**자주 쓰는 설정**


| 하고 싶은 것                     | 설정                                     |
| --------------------------- | -------------------------------------- |
| 스위치를 일정 시간 뒤 자동으로 꺼지게       | 스위치의 Auto Off Seconds에 초 입력 (0 = 안 꺼짐) |
| 밟고 있는 동안만 켜지게 (버티기)         | 발판 스위치의 Off When Left 체크               |
| 스위치를 켜면 문이 **닫히게** (장난 스위치) | 문의 Invert 체크                           |
| 문이 열리는 방향, 속도               | 문의 Open Offset, Move Time              |


**역할 교차 퍼즐 만들기** (A가 B의 문을 열고, B가 A의 문을 연다)

1. A 전용 세트를 씬에 놓고 우클릭 → Prefab → Unpack.
2. 문만 B가 가는 길로 옮긴다. 연결은 그대로 유지된다.
3. 반대쪽은 B 전용 세트로 똑같이 한다.

## 4. 진행 (체크포인트 · 낙사 · 골)


| 이름    | 경로                                                          | 설명                      |
| ----- | ----------------------------------------------------------- | ----------------------- |
| 체크포인트 | `Assets/02_Prefabs/Client/Level/Progress/Checkpoint.prefab` | 지나가면 저장됨. 죽으면 여기서 다시 시작 |
| 낙사 구역 | `Assets/02_Prefabs/Client/Level/Progress/KillZone.prefab`   | 닿으면 죽고 마지막 체크포인트로 돌아감   |
| 골     | `Assets/02_Prefabs/Client/Level/Progress/Goal.prefab`       | **두 사람 모두** 들어오면 CLEAR  |


- 체크포인트는 Order 값을 코스 순서대로 0, 1, 2… 로 **늘려가며** 준다. 구간마다 1개, 휴식 공간에 둔다.
- 낙사 구역은 떨어지는 경로 아래에 넓게 깐다. 원형으로 올라가는 코스라면 아래층 길을 덮지 않게 **코스 바깥쪽**에 둔다.
- 골은 코스 맨 끝에 1개.
