# 05_Docs 안내

## 폴더

| 폴더 | 넣는 것 |
| --- | --- |
| `00_공통/` | 주차와 상관없이 계속 고쳐 쓰는 문서: 계약명세, 기술스택, 현재 프리팹 리스트, 치트키 목록 |
| `01_전달사항/` | 클라↔서버 전달 문서. 작업 시작 전에 `미확인` 항목부터 읽는다 |
| `02_아트/` | 아트 에셋 요구 리스트, 톤앤매너, 아트 전달 문서 |
| `N주차/` | 그 주의 작업지시서. 주가 끝나면 고치지 않는다(남은 일은 다음 주 문서로 옮긴다) |

## 주차 문서 이름

`N주차/N주차_번호_이름.md` — 번호는 주마다 같게 맞춘다.

| 번호 | 문서 |
| --- | --- |
| `00` | 공통(일정·소유권, 필요할 때만) |
| `01` | 클라이언트 |
| `02` | 서버 |
| `03~` | 그 주에만 쓰는 추가 문서 (예: 코스디자인, 착수가이드) |

새 주차 시작: `N주차/` 폴더를 만들고 `N주차_01_클라이언트.md`, `N주차_02_서버.md`부터 쓴다. 지난주 남은 일은 새 문서의 "남은 일" 칸으로 옮긴다.

## 계약 변경

계약은 `00_공통/계약명세.md` 하나만 고친다. 주차 문서에는 "추가안"만 적고, 합의되면 계약명세에 버전(v0.4, v0.5…)으로 반영한다.
