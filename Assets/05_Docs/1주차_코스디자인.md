# 1주차 코스 디자인 — 나선 상승 핵심 재미 검증 코스

- 씬: `Assets/01_Scenes/11_SpiralCourse.unity` (10_DemoRoom 복사본에서 테스트 오브젝트 제거 후 제작)
- 루트: `SpiralCourse` 하위 `Z1_…` ~ `Z5_…`, `KillZones`, `CenterPillar`
- 목표 플레이 타임: 8~12분 (실수 포함, 2인 기준)

## 1. 전체 구조

중앙 기둥(`CenterPillar`, 높이 0~24)을 **반시계 방향으로 돌며 계속 올라가는 나선**. 체인 투게더식 공중 발판만으로 구성.

| 바퀴 | 반경 | 높이 | 내용 |
|---|---|---|---|
| 1바퀴 | R=16 | 0 → 11.4 | Z1 → Z2 → Z3 (출발점부터 미로까지) |
| 2바퀴 | A 레인 R=20 / B 레인 R=12 | 11.4 → 17.8 | Z4 (1바퀴 출발 구간 바로 위를 지나감) |
| 2.5바퀴 | R=10 | 17.8 → 21.3 | Z5 → 골 (1바퀴 Z2·Z3 위) |

- 위층에서 아래층이 내려다보인다. 지나온 길이 보여 "이만큼 올라왔다"는 감각을 준다.
- **실패 페널티 = 높이 손실.** 위층에서 바깥으로 떨어지면 아래층 코스에 착지할 수 있고, 그 지점부터 다시 올라와야 한다.
- 안쪽(기둥 쪽)이나 코스 밖으로 떨어지면 KillZone → 마지막 체크포인트에서 부활.
  - `KillZone_Floor`: y=-4, 약 96×97. 코스 전체 바닥.
  - `KillZone_Inner`: 기둥 주변 16×16, 윗면 y=8. 1바퀴 발판(R≥13.6)을 덮지 않는다.

## 2. 구간별 의도

### Z1 튜토리얼 — 색 다리 (Checkpoint_0, 높이 0 → 5.5)
- **구성**
  - `Hub0_Start` 쉼터.
  - 빨강/파랑이 번갈아 나오는 8줄 다리. 한 줄에 발판은 하나뿐이고, 왼쪽/오른쪽 레인 중 어디에 있을지 불규칙하다.
  - 공용 발판 3개로 계단식 점프 → `Hub1`.
- **의도:** "내 눈엔 이게 보이는데 넌 안 보이는구나"를 처음 깨닫는 구간.
  - 빨강 줄은 A만, 파랑 줄은 B만 보인다. 보이는 사람이 "왼쪽!" / "오른쪽!"을 불러줘야 한다.
  - 역할이 번갈아 바뀌어서 둘 다 말하는 쪽과 듣는 쪽을 모두 경험한다.
- **나와야 할 대화:** "다음 칸 왼쪽이야" / "나 이번 건 안 보여, 네가 불러줘"
- **난이도:** 최하.
  - 간격 0.2~0.7m, 줄마다 높이 +0.3.
  - 떨어지면 바닥 KillZone → 부활 0.5초. 페널티 거의 없음.

### Z2 안내 점프 — 파랑 지그재그 (Checkpoint_1, 5.5 → 9.6)
- **구성:** 파랑 발판 6개. 좌우 ±1.2m 지그재그, 간격 약 1.5m, 단마다 +0.6m.
- **의도:** B가 A를 **연속으로** 안내한다. Z1보다 거리와 높이가 붙어서 한 번 틀리면 떨어진다.
  - B가 먼저 건너가 "여기 서 있어"라며 위치 기준점이 되어 주는 플레이가 나오는지 관찰.
- **나와야 할 대화:** "내 쪽으로 뛰어" / "더 오른쪽, 조금만 더"
- **난이도:** 하.
  - 아래가 출발 지점 근처 바닥이라 낙하해도 Checkpoint_1로 부활.

### Z3 빨강 투명 미로 (Checkpoint_2, 9.6 → 11.4)
- **구성**
  - 10×15 바닥, 5×6칸(칸당 2m) 미로.
  - 바깥 테두리 = 공용 벽 (둘 다 보임). 내부 벽 20개 = 빨강 벽 (A만 보임, 충돌은 둘 다).
  - 막다른 길 5개. 정답 경로 14칸.
- **의도:** A가 **지도 역할**. B는 투명 벽에 부딪히며 A의 설명만으로 길을 찾는다.
  - A가 위에서 보는 게 아니라 같은 높이에서 보기 때문에, A도 직접 들어가서 같이 걸으며 설명하게 된다.
- **나와야 할 대화:** "거기 벽 있어, 한 칸 돌아와" / "왼쪽으로 꺾고 바로 앞으로 두 칸"
- **난이도:** 중하.
  - 낙사 없음 (사방이 벽). 시간만 쓰는 구간이라 **긴장 완화 / 휴식** 역할도 한다.

### Z4 스위치 분기 — 역할 교차 (Checkpoint_3 = 분기 직전 `Hub3`, 11.4 → 17.8)
- **구성:** `Hub3`에서 길이 두 갈래로 갈린다.
  - **A 레인 (바깥, R=20)**
    - 시작에 `Lever_Red_OpensBDoor`가 있다.
    - 파랑 발판 4개 (A에겐 안 보임 → B가 불러줘야 함).
    - `Door_LaneA_ByBlueLever`가 길을 막는다.
  - **B 레인 (안쪽, R=12)**
    - 시작에 `Lever_Blue_OpensADoor`가 있다.
    - 빨강 발판 3개 (B에겐 안 보임 → A가 불러줘야 함).
    - `Door_LaneB_ByRedLever`가 길을 막는다.
  - 두 레인은 `MergeHub`에서 합류한다.
  - 이어서 `Set_TimedSteps`: 공용 발판을 밟으면 4초간 계단 3개가 나타난다 → `Hub4`.
- **의도:** 이 코스의 핵심. **서로의 문을 서로가 열어줘야 한다.**
  - 각자 상대 레인의 발판 위치를 불러줘야 한다 (A 레인은 파랑 → B가 안내, B 레인은 빨강 → A가 안내).
  - 동시에 진행하면 두 사람이 서로 다른 레인에서 동시에 안내하는 상황이 된다.
- **장난 요소:** 레버는 토글 (`Lever.OnInteract` → `!state.IsOn`).
  - 문을 열어준 뒤 다시 당기면 상대 문이 닫힌다.
  - 다시 당기면 열리므로 진행이 막히지는 않는다.
  - 레버는 분기 시작 지점에 있고, 레인 끝에서 뒤로 돌아가면 다시 닿을 수 있다.
- **나와야 할 대화:** "레버 당겼어?" / "야 문 닫지 마!" / "네 쪽 다음 발판 안쪽이야"
- **난이도:** 중.
  - 레인에서 떨어지면 아래층(1바퀴 출발 구간)이나 바닥 KillZone → Checkpoint_3.
  - 시간제한 계단은 4초 안에 3단을 올라야 한다. 깜빡임 경고 있음.

### Z5 해머 구간 (Checkpoint_4 = `Hub4`, 17.8 → 21.3 → 골)
- **구성:** 다리 3개를 연속으로 지나 `GoalHub` (골은 둘 다 들어와야 클리어).
  1. `SliderBridge`: 느린 슬라이더 2개 (진폭 1.6, 주기 4, 위상 0/1). 워밍업.
  2. `HammerBridge`
     - 공용 해머: 둘 다 보임.
     - `Hammer_Blue_OnlyB`: B만 보임. 주기 2.0, 위상 0.9.
  3. `PusherBridge`: 바깥에서 안쪽으로 미는 푸셔 2개 (거리 3.2, 위상 0/1.5).
- **의도**
  - 파랑 해머는 A에겐 안 보인다. B가 "지금! 가!" 타이밍을 불러줘야 한다.
  - 푸셔는 안쪽으로 밀어 기둥 쪽 KillZone(부활)으로 떨어뜨린다.
  - 해머에 바깥으로 맞으면 **아래층 Z2/Z3에 떨어질 수 있다.** 가장 높은 곳에서 가장 큰 페널티 = 클라이맥스 긴장감.
- **나와야 할 대화:** "기다려… 기다려… 지금!" / "아 망치 보였으면 말을 해!"
- **난이도:** 상 (마지막 구간).

## 3. 난이도 곡선 · 쉼터 · 페널티 점검

| 구간 | 난이도 | 쉼터 (6×6) | 떨어지면 | 예상 시간 |
|---|---|---|---|---|
| Z1 | ★ | Hub0 | 부활 (Cp0) | 1~1.5분 |
| Z2 | ★★ | Hub1 | 부활 (Cp1) | 1~1.5분 |
| Z3 | ★★ (낙사 없음) | Hub2 | — | 1.5~2.5분 |
| Z4 | ★★★ | Hub3 | 부활 (Cp3), 일부 아래층 착지 | 2~3분 |
| Z5 | ★★★★ | Hub4 | 부활 (Cp4), 바깥 낙하 시 아래층으로 | 2~3분 |
| 합계 | | | | **약 8~11분** |

- 구간 사이마다 6×6 쉼터 + 체크포인트. 다음 구간을 내려다보며 상의할 시간이 있다.
- Z3(낙사 없음)를 Z2와 Z4 사이에 넣어 긴장 → 완화 → 긴장 리듬을 만들었다.
- 수치 검증 (에디터에서 스크립트로 측정)
  - 연속 발판 간 가장 먼 거리 1.56m (점프 한계 약 4.3m, 권장 ≤3m 충족).
  - 높이 차 0.3~1.0m (권장 ≤1.2m 충족).
- 전체적으로 **쉬운 편으로 설계했다.** 첫 플레이테스트에서 너무 쉬우면 Z2·Z4 발판 간격을 2~2.5m로 늘리는 걸 먼저 시도.

## 4. 오프라인 테스트 (F1/F2)

- 오프라인은 한 몸이 역할을 바꾸는 방식이라 **혼자서도 클리어 가능하게** 만들었다.
  - Z4 레버 두 개가 모두 `Hub3` 근처에 있다 → F1으로 빨강 레버, F2로 파랑 레버를 당긴 뒤 아무 레인으로 진행.
  - 시간제한 계단 = 공용 발판. 혼자 밟고 올라갈 수 있다.
- 테스트 순서: 각 구간에서 F1/F2로 보이는 발판·벽을 확인하며 진행. F6으로 체크포인트를 건너뛸 수 있다.
- 골은 둘 다 들어와야 한다 (온라인 기준). 오프라인 클리어 처리는 클라이언트 구현을 따른다.
