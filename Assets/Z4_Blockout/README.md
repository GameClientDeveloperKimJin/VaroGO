# Z4 시간제 숲 발판

대상: `MapDesign_Stage1_Z0~Z4` 씬의 `Z4_HiddenCrossing`.

- 기존 4개 발판 구간 + 12개 발판 구간 3개: 총 4트랙, 40발판.
- 기존 입구/CP2 안전지대와 새 고정 섬 3개. 새 섬에는 체크포인트(order 7~9), 돌 보충대(3자리), 숲 나무가 있다.
- `LocalSwitchState.autoOffSeconds`: 전체 진행 순서에 따라 12초부터 4.8초까지 선형 감소. 안전지대를 지나도 색상·시간 변화는 연속된다.
- 40개 전용 재질은 청록 `(0.18, 0.88, 0.78)`에서 주황빛 `(1, 0.32, 0.20)`까지 작은 간격으로 선형 보간한다. 위치별 색상이며 시간에 따라 다른 색으로 바뀌지 않는다.
- 트랙 1/2/3/4의 숨은 위치 힌트 담당은 A/B/A/B다. 담당 역할에게만 14% 투명도 힌트가 보이며, 다른 역할에게는 완전히 보이지 않는다. `Z4ExpiryWarning.hiddenHintRole`에서 트랙별 지정한다.
- 돌을 맞히면 기존 `RevealablePlatform`으로 출현하며 그동안 모든 역할에게 보이고 밟을 수 있다. 재차 맞히면 기존 스위치 로직이 유지 시간을 다시 채운다. 만료하면 다시 담당 역할에게만 힌트가 보이고 모두 밟을 수 없게 된다. 돌의 충돌 판정 자체는 역할로 제한하지 않는다.
- `Z4ExpiryWarning`: 남은 시간이 `min(3초, 전체 시간의 절반)` 안에 들어오면 밝기가 반복해서 낮아졌다가 돌아온다. 반복 주파수는 0.65→2.5Hz로 연속 증가한다. 경고 중에도 충돌은 유지하고, 만료 시에만 기존 출현 컴포넌트가 충돌을 해제한다.
- 경고는 기존 출현 알파와 타이머를 읽는 시각 효과다. 다른 구역의 `RevealablePlatform` 코드는 변경하지 않았다.
- 40개 발판의 좌우 위치, 간격, 회전을 고정 시드로 서로 다르게 배치했다. 같은 트랙 내 이웃 발판 중심의 수평 거리는 최대 약 6.25m다. 기존 색상/지속시간 진행 순서는 유지한다.
- 모든 안전지대의 `Stone_Supply_Stations`에 돌 보충대가 있다. 각각 3개 자리에서 돌이 없어지면 약 2초 후 보충한다. 보충대당 최대 12개를 유지하며, 한도에 도달하면 플레이어와 떨어진 곳에 정지해 있는 버려진 돌만 재사용한다. 들고 있는 돌, 날아가는 돌, 플레이어 주변의 돌은 회수하지 않는다.
- 아래로 추락하면 `KillZone`과 기존 부활 시스템이 마지막 활성 체크포인트로 돌려보낸다.
- 보충대에서 대기하는 돌은 물리를 고정해 굴러가지 않는다. 집기·던지기는 기존 돌의 상태 이벤트가 처리하며, 던지는 즉시 물리가 활성화된다. 새 돌의 지연 초기화를 먼저 완료한 뒤 고정한다.

`Timed_Forest_Tracks` 아래 새 트랙과 안전지대를 묶었다. `Materials`의 재질은 이 구역 전용이다. 편집 모드에는 발판 전체가 보이고, 플레이 모드에는 돌로 드러내야 한다.

백업·미리보기·검증 로그: `Captures/Z4/` 및 `Captures/Z4/RoleZigzag/`. 역할별 표시 검증은 오프라인 역할 전환으로 수행한다. `Z4StoneSupply`: 오프라인은 빈 자리에 새 돌을 만든다. 온라인(2026-11-22)은 새 돌을 만들지 않고, 처음 놓인 `Z4SupplyStone_Net` 돌(보충대당 3개)을 방장 PC가 빈 자리로 다시 가져다 놓는다. 떨어진 돌은 돌 자체가 시작 자리로 되돌린다.
