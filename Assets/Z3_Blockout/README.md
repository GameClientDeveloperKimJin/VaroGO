# Z3 숲 갈림길 블록아웃

대상 씬: `Assets/01_Scenes/MapDesign/MapDesign_Stage1_Z0~Z4.unity`

`Z3_ForkedForest/Z3_Pictorial_Forest`에 새 구역을 배치했다. 기존 Z3 오브젝트는 `Previous_Z3_Archived` 아래 비활성 상태로 보관한다.

## 그림 단서

- A: 무작위로 생성되는 4개 그림의 순서와 발자국. (DemoScene_1123은 4문제. 맵 디자인 씬은 7문제 그대로)
- B: 달–부엉이, 잎–사슴, 별–여우의 그림 연결.
- 갈림길에는 동물 그림만 표시한다. 각 그림을 B의 대응 정보로 해석해 올바른 동물 경로를 선택한다.
- 입구 표지판의 두 그림 레이어는 기존 `MagicVisibility`로 역할별 표시한다. 디버그 전체 표시를 켜면 두 레이어가 겹치므로 단서 확인 시 꺼야 한다.

## 지형과 오답 처리

7개의 숲 테라스에 각각 3개 경로를 배치했다. 매 라운드 정답 7개, 오답 14개이며 Z2 상부에서 진입하여 현재 Z4 입구로 연결된다. Fantasy Worlds 나무와 수풀·이끼 바위를 사용한다. 테라스 간격은 약 70m에서 38m로, 각 선택 트랙은 20m에서 13m로 단축했다. 세 경로는 판정 구간 뒤에서 합류하므로 정답이 바뀌어도 동선이 이어진다.

오답은 발판 붕괴 또는 튕김 후 `CP_Z3_Start`로 돌아간다. 진행도를 0으로 초기화하고 7개 정답을 모두 이전과 다른 값으로 다시 뽑는다. A의 7개 그림도 동시에 갱신한다. 추락 및 문제 순서 건너뛰기도 같은 초기화 처리를 한다. 튕김은 물리 힘이 아니라 제어된 궤적이며 수평 12m, 최고 높이 10m, 지속 시간 1.8초다. `Z3ForestPuzzle` Inspector에서 조정할 수 있다. 붕괴 발판의 판자 장식도 함께 움직이며 복귀 후 원상 복구된다.

Z2 지름길 버섯의 비어 있던 목적지 참조를 Z4 입구의 `CP_Z4_Shortcut_Arrival`로 다시 연결했다. 체크포인트 순서는 Z2 상부 3 → Z3 입구 4 → Z4 입구 5 → CP2 6이다. Z4 입구 체크포인트를 실제 지형 위로 이동해 비행 종료 후 추락하지 않도록 했다.

**온라인 (2026-11-22, DemoScene_1123)**: `Z3_Pictorial_Forest`에 NetworkObject + `NetForestPuzzleState`가 붙어 정답·진행도·라운드를 두 사람이 공유한다. 방장이 정답을 뽑고, 누가 틀리거나 떨어지면 두 사람 모두 새 라운드(새 정답·단서, 진행도 0)가 된다. 틀린 발판 붕괴 연출은 두 화면에 같이 나오고, 되돌아가는 이동은 각자 자기 캐릭터만 한다. 상대 때문에 라운드가 바뀐 뒤 앞 문제로 들어가면 입구로 돌려보낸다(새 라운드는 다시 만들지 않음). 복귀 직후 1초는 판정하지 않는다(온라인 순간이동이 다음 틱에 적용되는 사이 추락 판정이 한 번 더 들어가는 것 방지). 복귀 끝에는 입구에 0.25초 앉힌 채 기다렸다가 내려 준다(순간이동 전 낭떠러지 아래로 잠깐 돌아가 죽는 것 방지). 선택·추락 판정은 이번 생에 도착 판정을 지난 플레이어만 받는다(퍼즐 밖에서 죽고 부활할 때 추락으로 잡히는 것 방지).

## 4문제 축소 (DemoScene_1123, 2026-11-22)

`Seven_Question_Track`의 Question_01~04만 남기고 05~07과 `Next_Question_4~6`은 비활성. 시작(Question_01 위치)과 끝(`Z3_Exit_A`)은 그대로 두고 4개 구역을 가로·세로 1.83배로 키웠다(높이는 그대로라 점프 단차는 같다). `Next_Question_1~3`은 새 위치에 맞춰 다시 이었다. `forkReturns`·`correctBranches`·`clueVariants`는 4문제(단서 12개)로 줄였다. 위에서 본 모습: `Captures/Z3/FourQuestions/`.

## 작업 도구와 검증

`Tools > Hidden Path > Finish Z3 Forest`는 해당 씬 편집 모드에서만 실행한다. 숲 장식 그룹이 있으면 중복 생성하지 않는다. 실행하면 튕김 설정을 위 기본값으로 되돌리고 씬을 저장한다.

검증 결과와 역할별 표지판 미리보기는 `Captures/Z3/`에 생성한다. 구조 검사와 트리거 콜백 검사는 전체 경로의 수동 플레이테스트나 온라인 테스트를 대신하지 않는다.

## 회전 배치 정리

사용자가 회전한 구역의 진행 방향을 유지한다. `Seven_Question_Track/Question_01`~`Question_07` 아래에 동물 표지판, 수목, 트리거와 복귀 지점을 함께 묶었으며, 연결로는 `Aligned_Connections` 아래에 있다. 기존 4문제 배치는 `Four_Questions_Archived`에 비활성 보관한다. 개별 메시를 다중 선택해 회전하지 말고 구역 부모를 선택해야 판정과 장식이 함께 이동한다. 개별 문제를 옮기면 인접 연결로의 끝점은 별도 조정해야 한다.

튕김 방향은 해당 발판의 `forward`를 사용한다. Z4에서 회전 선택에서 빠졌던 충돌 지형과 부모 좌표도 시각적 배치에 맞췄다. 정리 전 사용자 배치 백업과 검사 결과는 `Captures/Z3/RotationCleanup/`에 있다.

7문제 확장 전 백업과 테스트 결과는 `Captures/Z3/SevenQuestions/`에 있다. 실제 버섯 `OnTriggerStay` 발사·착지·체크포인트 활성화, 100회 무작위 단서 동기화, 7문제 정답 진행, 오답 후 입구 복귀 및 새 라운드 교체를 오프라인에서 검증했다.
