# Z3 창고 협력 퍼즐 — 오프라인 조작 프로토타입

대상: MapDesign_Stage2. 기존 공용 플레이어 스크립트와 에셋은 변경하지 않는다.

## 테스트

Unity Play Mode → F6. 기존 씬 플레이어를 잠시 숨기고 두 테스트 캐릭터를 생성한다.
- WASD/마우스/Space: 이동·시점·점프. C: 엎드리기.
- Tab: 레드/블루 캐릭터 전환. 운반/연출 도중에는 전환하지 않는다.
- E: 가까운 물체 운반, 작업대에 배치, 어깨 올라타기, 밧줄 줍기/설치/끌어올리기.
- F: 완성된 계단 꼭대기에서 파트너 받쳐주기/해제.
- F8: 전체 퍼즐과 두 캐릭터 초기화.

## 흐름

52×38m 하층 창고, 운반 후보 34개, 고정 잔해 20개, 상층 선반 7개.
맞는 블록 네 개를 순서대로 골라 작업대 근처에서 E로 배치한다. 오답은 배치되지 않고, 작업대에서 떨어진 곳에서 E를 누르면 원위치에 내려놓는다. 임의로 모든 물체를 무한 적재하여 협동 높이를 우회하는 구조는 아니다.

첫 번째 큰 블록은 두 캐릭터가 가까이 있어야 들 수 있으며 함께 이동한다. 운반은 손 애니메이션/물리 적재의 최종 구현이 아닌 위치 추종 방식이다. 나머지는 한 명이 운반한다.

하층 바닥 6m, 완성 계단 꼭대기 10m, 개구멍 진입 턱 13.2m. 계단 꼭대기에서 F로 받쳐주고, 다른 캐릭터로 전환해 가까이서 E로 어깨를 밟는다. 이후 직접 Space 점프로 외부 턱에 도달하고 C로 엎드려 통과한다. 틈 높이 1.45m, 서 있는 캐릭터 1.8m, 엎드린 캐릭터 1.28m.

상층 서쪽의 가벽 뒤에서 밧줄을 발견한다. 동쪽 구조 고리에 설치하고, 아래 파트너를 밧줄 아래 표식으로 이동시킨다. 위 캐릭터가 고리에서 E를 누르면 3.5초 동안 파트너를 위로 올린다. 구조 완료 시 출구 문이 열린다. 높은 출구 다리에서 Z4로 내려간다.

## 검증 및 제한

Captures/Stage2_Z3/play-audit.txt: 실제 PlayerController/CharacterController로 네 계단 점프, 단독 최종 점프 실패, 어깨 점프 성공, 서서 개구멍 진입 차단, 엎드려 통과를 확인했다. 잘못된 크기 거부, 큰 물체 단독 운반 거부, 밧줄 상태 흐름, 동료 위치 검사, 구조 이동 완료, 출구 개방 및 초기화를 검사했다. 상태 검증의 준비 위치는 테스트가 배치했으므로, 사람이 처음부터 끝까지 수행한 2인 플레이 테스트와는 구분한다.

**오프라인 두 역할 전환용 프로토타입**이다. Fusion 온라인 동기화는 아직 구현하지 않았으며 온라인 세션에서는 테스트 시작을 거부한다. 테스트 캐릭터에만 복제한 튜닝을 적용하여 절벽 자동 잡기를 끄며, 원본 PlayerTuning과 다른 구역에는 영향이 없다. 어깨 올라타기와 밧줄 인양은 입력 잠금 후 보간하는 임시 연출이다. 실제 운반/협동 애니메이션은 후속 작업이다.

Builder: Editor/Z3WarehouseBuilder.Build (중복 적용 방지).
Audit: Play Mode에서 Editor/Z3PuzzleAudit.Setup → 어깨 이동 완료 후 AfterMount → 밧줄 이동 완료 후 Finish.

## 방 인테리어 배치 (2026-11-28)

격자 배치를 벽면 수납·작업실·중앙 공용 공간·남쪽 휴식 공간·북서쪽 폐자재 적재 공간으로 변경했다. 계층 Interior_Blockout의 5개 그룹을 기준으로 아트 리소스를 교체할 수 있다. 퍼즐 오브젝트의 루트 Z3Piece와 충돌체는 유지하고 시각부를 교체한다. 34개 운반 후보를 유지했으며, 겹친 물체 세 개를 분리했다. 초기화 시 위치뿐 아니라 원래 회전도 복원한다. 변경 후 기존 오프라인 퍼즐 검사를 재실행하여 통과했다.

## 혼합 기본 도형 및 협력 점프 재검증

오답 후보 23개를 원기둥 통 8개, 구형 돌 8개, 캡슐 자루 7개로 변경했다. 네 계단 부품은 평평한 윗면을 유지한다. 비균일 크기의 소품은 외형에 맞는 convex MeshCollider를 사용한다. 변경 후 실제 캐릭터 검사에서 최고 단 단독 점프는 실패하고, 파트너 어깨 높이 약 11.84m에서 점프하면 13.2m 턱에 착지 후 엎드려 개구멍을 통과했다. 밧줄 구조와 출구 개방도 재검증했다. 어깨 올라타기는 E 상호작용을 사용하는 오프라인 프로토타입 방식이다.
