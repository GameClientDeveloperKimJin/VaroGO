# Stage 02 dungeon rough layout — 2026-11-27

## 후속 공간감 보강

`Dungeon_Spatial_Pass`에 기본 도형 기반 석재 바닥·벽면, 기둥, 아치 문틀, 천장, 횃불 조명, 창고 소품, 다리 사슬, 그네 쇠살, 롤러 돌기 및 수정 제단을 추가했다. 플레이어 눈높이의 원근 시점에서 공간을 검토했으며 큰 개발용 문구와 예시 경로·이동 범위 안내선은 숨겼다. 유리는 투명 재질로 조정했다. 원래 발판·벽의 충돌 및 기믹 배치는 유지하고 추가 장식에는 충돌체를 넣지 않았다.

천장 때문에 Scene 탑뷰가 가려지면 `Dungeon_Spatial_Pass/Ceilings_HideForTopView`를 편집 중에 숨길 수 있다. 기믹 구현 및 최종 아트/최적화 단계는 여전히 별도다. 눈높이 미리보기와 변경 전 백업은 `Captures/Stage2_DungeonLook`에 있다. 이번 확인은 편집 모드 렌더 및 구조 검사이며 플레이 모드의 전 구간 완주 검증은 아니다.

작업 씬: `Assets/01_Scenes/MapDesign/MapDesign_Stage2.unity`

첨부된 전체 연결도와 Z1~Z8 상세 도면에 회의·멘토링 수정 사항을 반영한 **기본 도형 공간 뼈대**다. 완성 퍼즐, 온라인 플레이, 최종 아트 작업이 아니다. 기존 `HiddenPath_Stage2_Dungeon`은 비활성 상태로 보관한다. 새 배치는 `Stage02_Rough_20261127` 아래에서 구역별로 편집한다. 자동 실행·자동 재생성은 없다.

## 동선과 공간

- 주 경로: Z0 → Z1 → Z2 → Z4 → Z5 → Z6 → Z7 → Z8. 전체 도면과 상세 도면의 연결 순서가 다른 곳은 전체 연결도를 우선했다.
- Z3: Z2에서 서쪽으로 분기하는 선택 공간. 상층 방에서 Z4로 다시 연결된다.
- 진행 방향: 월드 +Z. 약 100m 폭 × 340m 길이의 초안이며 정확한 치수는 테스트 후 조정한다. 주 경로 바닥 높이는 0m에서 21m까지 상승한다.
- 천장은 편집 가독성을 위해 생략했다. 경계벽, 기둥, 문틀, 상층 바닥, 난간 대신 피신 공간 등은 큐브·실린더로 구성했다.
- 일반 바닥·벽에는 충돌이 있다. 안내선·표지·용암 표면은 시각 표시다. 오프라인 플레이어를 입구에 배치했지만 미구현 기믹을 포함한 전 구간 완주는 보장하지 않는다.

Z1의 `SWITCH_ON_TopView_RoleHint_Example_INACTIVE`와 `BrokenGlass_Example_INACTIVE`는 비활성 검토용 그룹이다. 기본 이동 상태에는 유리를 모두 동일하게 표시한다. 문양·힌트의 예시는 최종 정답 패턴이 아니다.

Z3의 상층은 하층보다 7.2m 높다. 공용 3개 높이 합 3.6m, 특수 각 1.4m로 두 특수 조각을 사용하는 적층 검토 기준을 잡았다. 실제 운반·중첩 충돌·파트너 밟기·매달리기까지 포함한 필수성 검증은 후속 단계다. 상층 복귀 램프의 역주행 허용 여부도 이때 결정한다.

Z5의 `Editor_ExampleRoutes_HIDE_FOR_PUZZLE`는 레벨 검토용 예시 동선이다. 현재 열린 문으로 A/B 각 입구에서 출구까지 연결된다. 최종 퍼즐에서는 표시를 끄고 실제 힌트와 문 연동 규칙으로 대체한다. 무작위 생성이나 힌트 해석 로직은 추가하지 않았다.

## 편집 및 검증

새 루트 하위의 Z0~Z8 그룹을 이용한다. 기존 맵을 동시에 활성화하지 않는다. 생성 메뉴는 대상 씬 경로를 검사하고 새 루트가 이미 있으면 재생성을 거부해 수동 편집을 보호한다.

원본 씬 백업, 씬 해시 비교, 구역별 이미지 및 검사 결과는 `Captures/Stage2_Rough_20261127`에 둔다. 구조 검사는 플레이 난이도 및 온라인 2인 검증을 대신하지 않는다.

이번 검사: 구역 9개, 유리 30개, 미로 방 16개·문 24개, 그네 6개. Z5 두 예시 동선의 232개 위치에서 플레이어 크기 캡슐과 바닥 레이 검사를 수행했고 막힘·바닥 누락이 없었다. 새 루트의 누락 스크립트는 0개이며, 기존 배치는 비활성 보관됨을 확인했다. 변경 전후 전체 씬 SHA256 비교 결과 대상 씬만 변경됐다. Z3 복귀 통로의 경계벽을 제거하고 개구멍 높이를 1.5m로 정리했다. 전 구간 수동 플레이 및 기믹 동작 테스트는 이번 구조 검증에 포함하지 않는다.
